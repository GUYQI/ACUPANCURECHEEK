# Cheek Acupuncture Atlas · אטלס דיקור הלחי (颊针)

Static, framework-free site served by GitHub Pages from the repository root (`index.html`). No build step.

## Structure

| Path | Purpose |
|---|---|
| `index.html` | Page structure and all static educational text (Hebrew, RTL). Contains the inline atlas SVG (layers: bones, 7 muscles, reference lines). |
| `css/app.css` | Design system: tokens, typography, components (cards, tabs, tables, accordions, callouts, stepper, video cards), atlas viewer, responsive rules, reduced-motion support. |
| `assets/` | `head-model.jpg` (3D head model used by the atlas and hero) and `reference-map.jpg` (original reference overlay). |
| `js/atlas-data.js` | Atlas datasets: 7 muscles, 16 points (coordinates calibrated to the 1000×828 model), study Table 1, protocol configurations. |
| `js/atlas.js` | Atlas logic: point/muscle selection, protocol modes, layer toggles, zoom/pan/pinch, keyboard navigation, 16-point table with search, filters and mobile cards. |
| `data/book-content.js` | Structured knowledge from the source book (points, muscles, theory, methods, diagnosis, safety, glossary, discrepancies), each item with a page reference. |
| `data/book-cases.js` | 101 clinical cases from book chapter 11 — generated by `tools/extract_cases.py`. |
| `js/knowledge.js` | Renders the book data into the atlas inspector and the educational sections; cross-links points, muscles, glossary and cases. |
| `js/app.js` | Navigation, scroll-spy, mobile menu, hero map, protocol steppers, reveal-on-scroll, scroll-to-top. |

To add or correct content, edit the data files; the UI renders from them.
